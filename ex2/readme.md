# Завдання 2: Обчислення визначеного інтеграла методом Монте-Карло

## Опис завдання

Програмно реалізовано алгоритм пошуку визначеного інтеграла за допомогою методу Монте-Карло для функції **f(x) = x²** на інтервалі **[0, 2]**.

## Аналітичне обчислення інтегралу

Для функції f(x) = x² на інтервалі [0, 2]:

```
∫₀² x² dx = [x³/3]₀² = (2³/3) - (0³/3) = 8/3 ≈ 2.6666666667
```

**Точне значення інтегралу: 8/3 = 2.6666666667**

## Результати обчислень

### Метод Монте-Карло

Метод Монте-Карло був застосований з різною кількістю випадкових точок:

| Кількість точок | Значення інтегралу | Абсолютна похибка | Відносна похибка |
|----------------|-------------------|-------------------|------------------|
| 100            | ~2.630            | ~0.037            | ~1.38%           |
| 1,000          | ~2.686            | ~0.019            | ~0.71%           |
| 10,000         | ~2.706            | ~0.040            | ~1.49%           |
| 100,000        | ~2.675            | ~0.009            | ~0.33%           |
| 1,000,000      | ~2.671            | ~0.004            | ~0.15%           |

### Обчислення за допомогою scipy.quad

Функція `scipy.integrate.quad` повертає:
- **Значення інтегралу:** 2.6666666667
- **Оцінка похибки:** 2.96×10⁻¹⁴

## Порівняльний аналіз

### Порівняння методів

1. **Аналітичне обчислення:**
   - Результат: 8/3 = 2.6666666667
   - Похибка: 0 (точне значення)

2. **scipy.quad:**
   - Результат: 2.6666666667
   - Похибка: 2.96×10⁻¹⁴ (практично нульова)
   - Метод: адаптивна квадратура (висока точність)

3. **Метод Монте-Карло:**
   - Результат залежить від кількості точок
   - З 1,000,000 точок: ~2.671 (похибка ~0.15%)
   - Метод: статистичне наближення

### Залежність точності від кількості точок

Спостерігається загальна тенденція зменшення похибки зі збільшенням кількості випадкових точок:

- **100 точок:** похибка ~1.38% (низька точність)
- **1,000 точок:** похибка ~0.71% (середня точність)
- **10,000 точок:** похибка ~1.49% (випадкові коливання)
- **100,000 точок:** похибка ~0.33% (добра точність)
- **1,000,000 точок:** похибка ~0.15% (висока точність)

**Важливо:** Через випадкову природу методу Монте-Карло, результати можуть незначно відрізнятися при кожному запуску. Однак загальна тенденція збільшення точності зі збільшенням кількості точок підтверджується.

- ✅ Простота реалізації

- ⚠️ Повільніший за аналітичні методи для простих функцій
